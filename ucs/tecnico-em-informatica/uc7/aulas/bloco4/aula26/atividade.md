# Atividade - Aula 26: Servidor web Apache + PHP

**Entrega:** Aplicação PHP publicada no APP01 com evidências de acesso pelos clientes.  
**Formato:** individual ou em dupla, conforme orientação do docente  
**Peso sugerido:** atividade do bloco

---

## Objetivo

Publicar a aplicação web em Apache e PHP no Ubuntu Server.

## Contexto

A NexaTech quer uma aplicação simples para a intranet no servidor Linux.

## O que deve ser entregue

Aplicação PHP publicada no APP01 com evidências de acesso pelos clientes.

## Etapas

1. Instalar Apache e PHP no APP01
2. Criar o virtual host da aplicação
3. Publicar a página inicial em PHP
4. Testar pelo navegador do CLI01 e do CLI02
5. Registrar a configuração e as permissões

## Evidências esperadas

- Documento ou planilha com as decisões e justificativas.
- Capturas de tela ou saídas de comando que comprovem a execução.
- Registro das dificuldades encontradas e como foram resolvidas.
