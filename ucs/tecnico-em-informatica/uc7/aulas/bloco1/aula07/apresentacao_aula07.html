Windows Server: Usuários, Grupos, Partição e Pastas

O grande laboratório prático de administração local no Windows Server: criação de partição dedicada (D:), governança de usuários por setor e permissões NTFS.

Carga: 3 horas Laboratório Prático Windows Server + Partição D:

Navegue com ← → ou utilize os botões no canto inferior direito.

Passo 1 · Armazenamento

Criando a Partição de Dados D: de 5 GB

Boas práticas de administração de servidores: NUNCA compartilhe pastas na unidade de sistema (C:).

Por que separar C: e D:?

  • Se usuários lotarem o disco com arquivos pessoais ou planilhas pesadas, a unidade D: enche, mas o Windows Server (C:) continua funcionando e não trava o boot.
  • Facilita rotinas de backup focadas apenas no volume de dados.

Como criar no diskmgmt.msc

  1. Abra o Gerenciamento de Disco (Win + R → diskmgmt.msc).
  2. Clique com botão direito no C: → Diminuir Volume em ~5.000 MB.
  3. No espaço não alocado gerado → Novo Volume Simples.
  4. Atribua a letra D:, formato NTFS e rótulo DADOS.
Passos 2 e 3 · Identidade

Criando Grupos e Usuários no Computer Management

Acesso via compmgmt.msc → Local Users and Groups:

1. Criar os Grupos

Criar G_Financeiro, G_Gerencia e G_Secretaria.

Grupos representam direitos coletivos; facilitam adicionar ou remover pessoas sem alterar permissões de pastas.

2. Criar os Usuários e Associar

Criar usuários financeiro, gerencia e secretaria com senha padrão.

Adicionar cada usuário como membro exclusivo de seu respectivo grupo.

Passos 4 e 5 · Segurança

Permissões de Compartilhamento vs. NTFS

Aba Compartilhamento (Sharing)

Compartilhamento Avançado → Marcar pasta → Nome do compartilhamento (ex: Financeiro).

Permissões: Adicionar o grupo G_Financeiro com permissão de Alteração (Change) e Leitura (Read).

Aba Segurança (Permissões NTFS)

Controla os direitos no disco. Adicionar G_Financeiro com permissão de Modificar (Modify).

Remover acessos indevidos de outros setores mantendo SYSTEM e Administradores.

Caminho UNC de Acesso: Clientes acessam através de \\192.168.10.2\Financeiro ou \\SRV-ARQUIVOS\Financeiro.
