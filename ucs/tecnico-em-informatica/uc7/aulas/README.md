# Aulas - UC7

Material organizado em **5 blocos** e **32 aulas de 3 h** (96 h).

```text
aulas/
  README.md
  bloco1/  Fundamentos e Planejamento (A01-A07)
  bloco2/  Windows Server (A08-A15)
  bloco3/  Redes, Roteamento e Firewall (A16-A19)
  bloco4/  Linux Server e Segurança (A20-A29)
  bloco5/  Operação, Monitoramento e Projeto (A30-A32)
  projeto-integrador/
```

> A **Aula 00** é a abertura da UC e não conta nas 32 aulas: [Slides](bloco1/aula00/apresentacao_aula00.html) · [Guia](bloco1/aula00/README.md).
>
> A base comum do laboratório fica em [`../laboratorio_virtual/`](../laboratorio_virtual/README.md) e usa **VirtualBox manual**, sem Vagrant.
>
> Conteúdo de **computação em nuvem** é extra em [`../extras/computacao-em-nuvem/`](../extras/computacao-em-nuvem/README.md).
